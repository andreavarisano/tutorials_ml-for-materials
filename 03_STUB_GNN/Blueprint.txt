1.1] Before using out-of-the-box GNN, let's implement a simple simple crystal message-passing model using PyTorch Geometric.
  For each structure:
  nodes:      atoms;
  node input: atomic number or learned elemental embedding;
  edges:      neighbors within a cutoff under periodic boundary conditions;
  edge input: interatomic distance expanded in radial basis functions;
  message passing: scalar features only;
  readout: sum or mean over atoms;
  output: scalar refractive index.

  Schematically:
	m_ij = ϕ_m( h_i , h_j , RBF(r_ij) )
	h_i^(layer l+1) = ϕ_u( h_i^(layer l) , ​∑_j∈N(i) m_ij   )
	output= pooling_i( h_i^(L) )
	-> Because the model consumes only atomic identities and distances, and uses permutation-invariant neighbor aggregation and global pooling, its scalar prediction is invariant.
